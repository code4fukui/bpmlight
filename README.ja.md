# bpmlight - ビートに合わせて点滅

指定したBPM（Beats Per Minute）に同期してiPhoneのLEDフラッシュライトを点滅させるiOSアプリです。速度、波形、明るさを調整して、独自の光のパターンを作成できます。

![bpmlight UI Screenshot](https://user-images.githubusercontent.com/5879/288009231-1e649082-136a-4c2e-836d-109249688448.png)

## 機能

-   **BPM制御**: スライダーを使って0〜300 BPMの範囲で点滅速度を調整できます。
-   **波形パターン**:
    -   **Linear**: 0%から100%まで明るさを直線的に立ち上げる鋭いノコギリ波。
    -   **Sine**: 滑らかに明るさがフェードイン・フェードアウトするパルス。
-   **明るさ制御**: ストロボ効果の最大輝度を設定します。すべてのパターンはこの設定を基準にスケーリングされます。
-   **手動操作**: BPMタイマーとは独立して、専用ボタンでフラッシュライトを即座に完全にONまたはOFFにできます。
-   **リアルタイム調整**: 点滅中であっても、すべてのパラメータ（BPM、波形、明るさ）をリアルタイムに変更できます。

## 必要要件

-   iOS 18.5以降
-   LEDフラッシュライトを搭載したiPhone

## インストールと使用方法

このアプリはApp Storeでは公開されていません。Xcodeを使用してソースコードからビルドする必要があります。

1.  このリポジトリをローカルマシンにクローンします。
2.  Xcodeで `bpmlight.xcodeproj` を開きます。
3.  iPhoneを接続し、ビルドターゲットとして選択します。
4.  Xcodeの「Run（実行）」ボタンを押して、アプリをビルドしデバイスにインストールします。

### アプリの使い方

1.  **BPMの設定**: 「BPM」スライダーを使って希望のテンポを設定します。
2.  **波形の選択**: 「Linear」または「Sine」をタップして点滅パターンを選択します。
3.  **明るさの調整**: 上部の「brightness」スライダーを使ってフラッシュの最大輝度を設定します。
4.  **点滅の開始**: **START** ボタンをタップします。
5.  **点滅の停止**: **STOP** ボタンをタップします。

**ON** および **OFF** ボタンを使用して、シンプルな手動の懐中電灯としてアプリを使用することもできます。
